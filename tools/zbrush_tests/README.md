# ZBrush 实测脚本

用法：ZBrush 主窗口加载完成后，执行 `ZBrush.exe <脚本绝对路径>`（路径用正斜杠），脚本会交给已打开的实例运行。
脚本里的工作目录（`lgDir`）写死为 `C:/zbt/`，复用前先建好这个目录或改路径。

- `make22.txt` / `make25.txt`：建一个带 Home/Target 阶段、2 级细分的球，导出参考 OBJ，存 `stg22.ztl` / `stg25.ztl` 并回读。
- `load_25to22.txt`：在 2022 中加载转换结果，记录阶段状态并导出 OBJ（`cmp.py` 逐顶点比对）。
- `genload.sh 文件 标签`：生成加载真实多子工具文件的脚本，逐个子工具记录名称、细分、阶段。
- `samples22.txt` / `samples25.txt` / `tex25.txt`：在两个版本里做同样的样本（普通、变形目标、图层、ArrayMesh、贴图），用来对比结构。
- `probe25.txt`：在 2025 中打开文件，逐个子工具读取 ArrayMesh / NanoMesh 等状态。
- `exp25.txt`：在 2025 中逐个子工具导出 OBJ（`g25_<序号>.obj`），作为几何基准。
- `loadtex.txt`：在 2022 中依次加载转换结果，记录子工具，并把 suti9 的子工具导出为 `g22_<序号>.obj`。
- `slots.py`：统计网格块尾部"槽位"标志（附属数据前后各有多少个零标志字节）。
- `ztl.py`：块树解析器（可原样重建文件，用于分析）。

注意：加载 ZBrush 不认识的文件会弹出报错框或直接崩溃，脚本会停住，需要手动关掉。ZBrush 异常退出后，下次启动会先弹出一个 Note 提示框，也要手动点确定，脚本才会运行。
