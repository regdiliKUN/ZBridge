# ZBridge — ZBrush 跨版本文件桥接器（独立可执行版）

把 ZBrush 的 `.ztl` 工程文件在不同 ZBrush 版本之间转换、并一键导出 GoZ 的桌面工具。
内置 20 个版本节点，支持**非线性自由版本跳转**（任一版本可直达集合内其他任意版本）。

## 功能

- **多版本转换**：版本注册表驱动，20 个节点（`3.1 → 3.5 → 4.0 → 4R2 → 4R4 → 4R6 → 4R7 → 2018 → 2019 → 2020 → 2021 → 2021.5 → 2021.6 → 2022 → 2023 → 2023.1 → 2024 → 2024.1 → 2025 → 2026`）
- **版本跳转**：在预设集合中任意 / 随机 / 自由组合跳转，**不要求线性、不要求连续**
- **GoZ 一键导出**：与 ZTL 转换同等级的单按钮流程
- **完整状态机**：空状态 / 进行中 / 失败 / 大版本不兼容
- **安全闸门**：未验证的跨代链路一律拦截，**绝不静默写坏文件**；仅勾选"强制"才放行
- **非破坏式输出**：生成 `原名_to<版本>.ztl`，原文件不动

## 快速开始

### 方式一：直接下载便携包（推荐，无需 Python）

到 [Releases](../../releases) 下载 `ZBridge_Portable.zip`，解压后双击 **`ZBridge.exe`** 即可。
整个目录自包含，可整体复制到任意机器 / U 盘运行，不依赖外部环境。

### 方式二：从源码运行

```bash
pip install -r requirements.txt     # 运行时其实只有标准库 + Tkinter
python src/zbridge.py               # 启动 GUI
```

### 命令行模式

```bash
python src/zbridge.py --report      # 输出最大可跨越代数与传递逻辑报告
python src/zbridge.py --selftest    # 无界面自检（检测/转换/拦截）
python src/zbridge.py --verify-all  # 对 20x20=400 个版本对做全量验证矩阵
```

## 最大可跨越代数与传递逻辑

- 每个 ZBrush 版本 = 谱系中的一个**节点**；架构最大连续跨度 = 节点数 − 1 = **19 代**。
- **边 = 一代标记**：相邻两代之间只改写该代专属字节标记（REV / REC / 头串），互不干扰。
- **多级跨越 = 边链**：`source → … → target`，每跳只改写一代标记。
- **集合内任意直达**：对子集一次性应用所需的全部标记改写，非线性、非连续。
- 真实可用跨度取决于各代标记是否已在真实 ZTL 上校准 —— 见下方"边界"。

## 验证状态（诚实说明）

| 项 | 结果 |
|---|---|
| 版本节点 | 20（有序版本对 400，非自环 380） |
| **ZBrush 保真度已验证直跳** | **2 对**：`2025 ↔ 2022` |
| 未验证（安全闸门拦截） | 378 对 |
| 全量矩阵逻辑一致性 | **380 / 380 一致，0 逻辑缺陷** |
| 模块保真度测试 | **43 / 43 通过**（13 模块，7 项已记录偏差） |
| 绿色包 / 快捷方式核验 | **16 / 16 通过** |

**必须知道的边界**：ZTL 是 ZBrush 私有格式，工业级可靠转换需要 ZBrush C++ SDK 与真实版式标记。
本程序采用已证实的"头部标记改写"技法，并把标记外置为可扩展注册表。除 `2025 ↔ 2022` 外，
其余 378 对在补全真实标记前**会被拦截而非静默损坏文件**。

要解锁更多版本：在 `src/zbridge.py` 的 `BY_ID` / `DIRECT_MARKERS` 中填入对应版本的
真实 REV / REC / 头串即可，无需改动架构。建议优先解锁"相邻 1 代"的 38 条。

## 仓库结构

```
src/zbridge.py               主程序（引擎 + GUI，零第三方依赖）
tools/test_fidelity.py       模块化保真度测试套件（43 项断言）
tools/audit_378.py           378 条未验证版本对逐条审计
tools/create_shortcut.py     创建指向包内 exe 的桌面快捷方式
tools/verify_shortcut.py     快捷方式四项硬性要求核验（16 项）
tools/parse_lnk.py           .lnk 二进制结构解析（MS-SHLink）
tools/render_report.py       由测试结果渲染结构化报告
docs/说明.md                 完整说明（代数、传递逻辑、打包与验证方法）
docs/测试报告.md             结构化保真度测试报告
docs/全量跳转验证矩阵.txt     400 个版本对的全量验证输出
build.py                     一键构建绿色目录包
```

## 构建绿色目录包

```bash
pip install pyinstaller
python build.py
```

产物在 `dist/ZBridge/`：`ZBridge.exe` + `_internal/`（全部依赖），双击即运行，无需外部 Python。
